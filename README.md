# Zombie Tag

A silly, cartoony 3D first-person game invented by Chloe and Naomi.
Bonk goofy zombies, pop them into confetti and Tag Bux, spend your Tag Bux at the shop and get strong at the gym!

The full plan is in [DESIGN.md](DESIGN.md). The game is being built in small steps, play-testing after each one.

## Build steps

- [x] **1. Walk and bonk:** walk around Sunny Park and pop Shufflers into confetti.
- [x] **2. Tag Bux and the shop:** collect coins from popped zombies and buy the Foam Noodle Bat and Water Blaster.
- [x] **3. Hearts:** zombie touches cost hearts, Heart Medicine in the shop, and getting tagged sends you back to the start.
- [x] **4. The gym:** treadmill and weights mini-games that raise Speed and Strength.
- [x] **5. All the weapons and armour:** ten weapons up to the Sparkle Star Laser Gun, and three kinds of armour.
- [x] **6. Two players:** split screen, a second set of keys, separate wallets and giving Tag Bux.
- [x] **7. Character creator and outfits:** type your name, pick your look, and buy cool outfits.
- [x] **8. Levels 1 to 10:** ten places, new zombies, the Zombie King, level select and saving.
- [x] **8b. Sound and music:** boings, pops, ka-chings, squawks and a tune for every place.
- [ ] **9. Refinement:** tuning from play-testing. Done so far: Easy, Hard and Hardcore, a hero for
  everyone on "Who's playing?", the gym limited to one upgrade per place, the Zombie King as the final battle,
  joypads (simple or two sticks), keyboard or joypad for each player, mouse controls, and Hardcore as its own fresh game with twice the zombies.

## How to play

On the start screen, choose **1 Player** or **2 Players** with W / S (or the arrows) and press Space.
Then each player picks her hero on **Who's playing?**, Player 1 first, chooses how hard, and picks a level.

**Keyboard or joypad:** on **Who's playing?** the button you pick your hero with decides what you play
with: **Space** for the ⌨️ keyboard (and mouse), or **fire on a joypad** for that 🎮 joypad. If
Player 1 picks with the keyboard, Player 2 can pick with a joypad, or press **Enter** to share the
keyboard: Player 1 then uses W A S D + Space (and the mouse, if mouse controls are on) and Player 2 uses
the arrows + Enter. If Player 1 picks with a joypad, Player 2 can have the keyboard or another joypad.
Each name tag (top right) shows 🎮, 🖱️ or ⌨️.

**Who's playing?** Everyone has their own saved hero, with her own looks, Tag Bux, weapons, outfits,
training and levels reached, so anyone can play as Player 1 or Player 2. Choose **➕ New hero** to make
another one (up to 8). Press **X** on a hero to delete it (it asks first).

**How hard?** Choose with A / D and press Space. The game remembers your choice for next time.

| | Getting tagged | The Zombie King |
| --- | --- | --- |
| 🙂 **Easy** | Back at the start, keeping everything | As below |
| 😬 **Hard** | Back at the start, but your weapons and armour are gone (you get a new Spiky Stick) | 10 times the health, faster, and tags you in one go, even through armour |
| 💀 **Hardcore** | Only 1 life! Game over, and your Hardcore game starts again from level 1 | 10 times the health, faster, and tags you in one go |

On Easy and Hard you always keep your looks, outfits, training and levels.

**Hardcore is a separate game.** Each hero starts it fresh, with only a Spiky Stick, no Tag Bux,
Speed and Strength 1 and only level 1 open; nothing comes across from Easy or Hard except your
outfits. There are **twice as many zombies**, with twice as many about at once. Your Hardcore game is
saved like the normal one, so you can stop and come back, until you get tagged: then it starts again
from nothing. Beating the Zombie King finishes it too, so your next Hardcore game starts fresh. Your Easy and Hard game is never touched. On Hardcore with 2 players, a tagged sister
is out until the other one finishes the level; if you're both tagged it's game over.

The first time, each new hero is made in the **character creator**: type your name (up to 12 letters)
and press Enter, then pick your skin, hair style, hair colour and clothes colour with W / S and A / D
(or your joypad) while your hero turns round to show off. Press Space (or fire) on **Done!**. With 2 players, Player 1 goes first. To change your looks later, press **C** on the start screen.
With 2 players the screen splits down the middle: Player 1 on the left, Player 2 on the right.

| Action | ⌨️ Keyboard | 🎮 Joypad (Simple) |
| --- | --- | --- |
| Walk forward / back | W / S (or ↑ / ↓; sharing: Player 2 uses only the arrows and Enter) | left stick or d-pad up / down |
| Turn left / right | A / D (or ← / →) | left stick or d-pad left / right |
| Attack (hold it down for shooting weapons and the laser) | Space (or Enter) | any face button (A B X Y, ✕ ○ □ △) or right trigger |
| Shop and gym: choose / go | W / S, then Space | up / down, then fire |
| Treadmill | A, D, A, D… as fast as you can | left, right, left, right… |
| Weights | tap Space as fast as you can | tap fire |
| Pause: volume, controls, or Q to go back to the start screen | Esc | Start |
| Level picker: choose / play | W A S D, then Space | stick, then fire |

You don't need to aim exactly: your weapon goes for the nearest zombie in front of you.

**Joypads** (Xbox, PlayStation or Switch Pro controllers, plugged in or Bluetooth) work every menu.
Press a button once after connecting so the browser notices it; the start screen shows how many it can
see. A joypad only moves a hero once someone has picked with it on **Who's playing?**. Typing a new
hero's name still needs the keyboard. One controller sometimes shows up as two (for example with Steam
running); that's fine, both go to the same player.

**Two sticks:** press **J** on the start screen, or change "🎮 Joypads" in the pause menu, to switch
joypads from **Simple** to **Two sticks**: the left stick walks and steps sideways, and the right stick
turns. The browser remembers your choice, and it's the same for every joypad.

**Mouse controls:** press **M** on the start screen, or change "🖱️ Keyboard" in the pause menu, to
switch the keyboard player between **Simple keys** (A / D turn) and **Mouse**: W / S walk, A / D step
sideways, the mouse turns and a click attacks. Click the game once to grab the mouse; Esc lets go of it
and pauses. The browser remembers your choice.

Popped zombies burst into spinning **Tag Bux** coins. Walk over them to collect them;
your Tag Bux are at the top right. A Shuffler is worth 5, so popping all 8 earns 40.

### Levels

Pop every zombie, then walk through the **glowing exit gate** at the far end of the path (look for the
beam of light) to finish the level. Each level unlocks the next one, and you can play any level you've
reached again from the level picker to earn more Tag Bux. The shop and gym are in a different spot each time.

| Level | Place | Zombies (1 player) | New zombie |
| --- | --- | --- | --- |
| 1 | 🌳 Sunny Park | 8 | Shuffler |
| 2 | 🏫 School and Playground | 10 | |
| 3 | 🛒 Supermarket Car Park | 12 | Speedy Sid: sprints, then stops to pant |
| 4 | 🏖️ Beach and Pier | 14 | |
| 5 | 🎡 Funfair | 16 | Bouncy Bob: hops right over fences and benches |
| 6 | ⛄ Snowy Village | 18 | Big Bertha: huge, and takes 2 hearts |
| 7 | 🧸 Toy Factory | 20 | |
| 8 | 🍄 Haunted Forest | 22 | Slime Zombie: splits into two little Shufflers |
| 9 | 🎃 Graveyard at Night | 25 | |
| 10 | 🏰 Zombie King's Castle | 30 + the King | 👑 The Zombie King: the final battle once every other zombie is popped. He arrives with 6 guards (12 on Hardcore) and calls Shufflers to help (2 at a time, or 4 on Hard and Hardcore) |

Zombies get tougher on each level, so keep training and upgrading. Beat the Zombie King and all the
zombies become your friends for a big party!

**Saving:** each hero's progress saves by itself at the start of each level, when you leave the shop
or gym, and when you get tagged, so you can stop and carry on another day. To start a hero again from
scratch, delete her on **Who's playing?** and make a new one.

### Sound and music

Every sound is made by the game itself, so there are no sound files: boings and pops for hits, a
ka-ching for every coin (higher and higher as you scoop up a pile), a squawk for the Rubber Chicken
Hammer, pew-pew for the laser, silly zombie groans, and fanfares for training, finishing a level and
beating the Zombie King. Each place has its own tune; the haunted forest, graveyard and castle are a
little spookier. Turn the music or sounds up and down in the pause menu (Esc). Sound starts after the
first key press, because browsers don't allow it before that.

### Playing together

Each sister has her own hearts, Tag Bux, weapons, armour and training. Coins go to whoever touches them
first. In the shop you can **🎁 Give 10 Tag Bux** to your sister as many times as you like, and the coins
fly across the screen into her counter. There are 50% more zombies with two players,
and zombies chase whichever hero is nearest. If one of you gets tagged, she's back at the start after
10 seconds while the other keeps playing.

### Hearts

You have **3 hearts** (top left). A zombie touch costs 1 heart, then you blink for 2 seconds and
can't be hurt, so run away! Lose all 3 and you're **TAGGED**: after a 3-second countdown you're back
at the start with 3 hearts, and on Easy you keep your Tag Bux and weapons (see **How hard?** above). A zombie that tags you gets
bumped back and goes dizzy (stars round its head) for a moment, so you can get away. Turn round and
run: you're faster than a chasing zombie going forwards, but a bit slower walking backwards.

Look for the **glowing pink shopping bag** above the trees and walk in through the shop door.
Zombies can't get in. In the shop:

| Weapon | Price | Power | What's special |
| --- | --- | --- | --- |
| 🪵 Spiky Stick | Free | 1 | Breaks after 4 hits. Get a free one any time you have no weapon. |
| 🏏 Foam Noodle Bat | 25 | 2 | Never breaks. Bonks zombies back. |
| 💦 Squirty Water Blaster | 60 | ⅓ | Shoots super fast. Pushes zombies away. 3 squirts pop a Shuffler. |
| 🐔 Rubber Chicken Hammer | 120 | 4 | SQUAWK! Bonks every zombie in front of you at once. |
| 🧪 Slime Slinger | 200 | 3 | Green goo makes zombies slow for 3 seconds. |
| 🧼 Bubble Blaster | 350 | 3 | Traps a zombie in a floating bubble for 3 seconds. |
| ❄️ Snowball Cannon | 500 | 5 | Freezes zombies solid for 2 seconds. |
| 🍌 Boomerang Banana | 700 | 6 | Flies out and comes back, hitting zombies both ways. |
| 🎃 Pumpkin Launcher | 1,000 | 10 | Slow, but each pumpkin splats every zombie nearby. |
| 🌟 Sparkle Star Laser Gun | 1,600 | 8 | The best weapon! Hold Space for a sparkly laser with swirling stars. |

Zombies that are bubbled, frozen or dizzy can't tag you.

**Armour** takes hits for you before your hearts do. It shows as blue shields next to your hearts
and fills back up at the start of each level (and when you get tagged). Only your best armour counts.

| Armour | Price | Blocks |
| --- | --- | --- |
| 📦 Cardboard Box Armour | 40 | 1 hit |
| 🏈 Sports Pads and Helmet | 150 | 2 hits |
| 🛡️ Shiny Knight Armour | 600 | 3 hits |

**Cool outfits** are just for looks, and your sister sees them on your hero:
🏴‍☠️ Pirate Hat (40), 🦸 Superhero Cape (50), 🦄 Unicorn Onesie (80), 🩰 Sparkly Dancer Outfit (100),
🧑‍🚀 Astronaut Suit (150) and 👑 Golden Crown (300). You can wear a hat and a cape together; putting on
something that covers the same place takes the other one off. Choose an outfit you're wearing to take it off.

The shop list scrolls: keep pressing S to see everything. It also sells **💊 Heart Medicine** (15 Tag Bux), which gives back 1 heart. Zombies wait outside
the door, so you get 2 safe seconds when you walk back out.

A new weapon goes straight into your hand. You keep every weapon you buy and can swap
which one you hold in the shop. Choose **Leave** to go back outside.
When you play again, you keep your Tag Bux and weapons, so after two clears you can afford the Water Blaster.

## The gym

Look for the **glowing blue dumbbell** above the trees and walk in through the door. Training is free,
but each place only lets you raise **Speed once and Strength once**, so you get stronger as you go
through the levels instead of maxing out in Sunny Park. Replaying a place doesn't give you more.

- **🏃 Treadmill (Speed):** press A, D, A, D… as fast as you can. Pressing the same key twice doesn't
  count. Fill the bar in 15 seconds for +1 Speed. Each level needs a few more presses.
  Every Speed level makes you 10% faster.
- **🏋️ Weights (Strength):** pick a dumbbell, then tap Space as fast as you can to lift it to the top
  in 10 seconds. It sinks if you stop! Every Strength level makes all your weapons hit 20% harder.

| Dumbbell | Sinks | Gets your Strength up to |
| --- | --- | --- |
| 🔵 Small | slowly | 4 |
| 🟠 Medium | quicker | 7 |
| 🔴 Heavy | very quickly | 10 |

If you don't make it, nothing is lost: just try again. Beat your fastest time for a **PERSONAL BEST!**
Speed and Strength go up to 10 (so you can reach the top by the last levels), and you keep them when
you play again or get tagged.

## Running it

You need **Node.js** (version 18 or newer) to run the game. It runs in a web browser:
it's been play-tested in **Chrome** and **Edge**.

To get the game onto your computer, either download it from GitHub (the green **Code** button, then
**Download ZIP**, and unzip it) or, if you have git:

```
git clone https://github.com/bennywebb/zombie-tag.git
```

The game opens at <http://localhost:5173>. Keep the terminal window open while playing; close it
(or press **Ctrl+C** in it) when you've finished. Progress is saved in the browser, so use the same
browser each time.

### Windows

1. Install **Node.js** (the "LTS" version) from <https://nodejs.org>. You only need to do this once.
2. **Double-click `start-game.bat`** in the game folder. The first time, it spends a minute installing;
   then the game opens in your browser.

Or, in a terminal in the game folder: `npm install` (just the first time), then `npm run dev`.

### Mac

1. Install **Node.js** (the "LTS" version) from <https://nodejs.org>: download the macOS installer and
   double-click it. You only need to do this once. (If you use Homebrew, `brew install node` works too.)
2. Open **Terminal** (press Cmd+Space, type *Terminal*, press Return).
3. Type `cd ` (with a space after it), drag the game folder from Finder into the Terminal window,
   and press Return.
4. The first time only, install the game's parts:

   ```
   npm install
   ```

5. Start the game:

   ```
   npm run dev
   ```

   The game opens in your default browser. If that's Safari, copy the address into Chrome instead.

Next time, just do steps 2, 3 and 5.

### Linux

1. Install **Node.js** 18 or newer. Check what you have with `node --version`. Many distributions
   ship an older one, so if it's missing or below 18, get the "LTS" version from <https://nodejs.org>
   (or with [nvm](https://github.com/nvm-sh/nvm): `nvm install --lts`).
2. In a terminal, go to the game folder and install the game's parts (first time only):

   ```
   cd zombie-tag
   npm install
   ```

3. Start the game:

   ```
   npm run dev
   ```

   The game opens in your default browser. If it doesn't, open <http://localhost:5173> in Chrome yourself.

### Getting the newest version

If you used git, run `git pull` in the game folder, then `npm install` (in case anything new is needed)
and start the game as usual. If you downloaded the ZIP, download it again. Your progress is kept
either way, because it's saved in the browser, not in the game folder.

## Changing the numbers

Speeds, damage, prices, hearts, gym difficulty, zombies, and each level's zombie count, toughness and mix are all in [`src/config.js`](src/config.js).
Edit a number, save, and the game reloads by itself.
